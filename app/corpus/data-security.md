# Data Security Policy

All company data is classified into three tiers: Public, Internal, and Restricted. Restricted
data (customer PII, financial records, security credentials) may not leave company-managed
systems.

## Third-Party Tools

Uploading Restricted data to any tool not on the approved vendor list (see
`software-licensing.md`) is a policy violation and must be reported through the process in
`incident-response.md`.

## Annual Review

Security conducts an annual review of tool usage and flags any shadow IT found during that
review, cross-referenced against Procurement's approved vendor list.
