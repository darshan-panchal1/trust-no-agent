# Software Licensing Policy

All software purchases, including SaaS subscriptions, go through Procurement — not through an
individual employee's corporate card, regardless of the amount.

## Approved Vendor List

IT maintains an approved vendor list for common software categories (productivity, design,
engineering tooling). Purchasing from an approved vendor skips the compliance check described in
`vendor-approval.md`.

## Shadow IT

Software purchased outside this process ("shadow IT") is not eligible for reimbursement and may
be flagged in the annual security review — see `data-security.md`.
