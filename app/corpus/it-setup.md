# IT Setup for New Employees

IT provisions a laptop and standard accounts (email, chat, calendar) before the employee's
start date, based on the offer letter's start date in the HR system.

## Software

Standard software (productivity suite, chat client, VPN) is pre-installed. Role-specific
software requests go through the process in `software-licensing.md`.

## Access Requests

Access to systems beyond the standard set requires manager approval, submitted through the same
badge-access request flow described in `badge-access.md`.
