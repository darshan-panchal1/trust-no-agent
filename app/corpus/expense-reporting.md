# How to File an Expense Report

Expense reports are filed through the internal Finance portal. Each report requires:

1. A cost center code, obtained from your manager
2. An itemized list of expenses with category tags
3. Receipts for any single item over $25
4. A one-line business justification per item

Reports are reviewed by your direct manager first, then routed to Finance for payment
processing. Typical turnaround from submission to reimbursement is 7–10 business days.

## Common Rejection Reasons

- Missing receipt for an item requiring one
- Cost center code does not match an active project
- Category tag does not match the expense description
